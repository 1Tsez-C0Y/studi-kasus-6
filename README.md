Penjelasan singkat

`while true` disini digunakan buat menampilkan daftar menu pilihan yang berulang. menu pilihan

1. Jika user memilih menu 1, program akan membaca file `iventaris.csv` baris demi baris menggunakan `csv.reader` dan memuatnya ke dalam daftar list bernama `Bar`. Jika daftar di `csv` tersebut kosong, program akan menampilkan pemberitahuan bahwa data masih kosong. Sebaliknya, jika ada data di `csv`, program akan menampilkan setiap barang beserta informasi nama, jumlah, dan harga satuannya.
2. Pilih menu 2, user diminta menginput nama, jumlah, dan harga barang baru. Kemudian akan ditulis ke baris baru dalam file `csv` menggunakan `csv.writer`
3. Pilih menu 3, berfungsi untuk menghentikan perulangan program dengan perintah `break`, sementara blok `else` berfungsi menangani input yang tidak sesuai dengan pilihan menu yang ada.
